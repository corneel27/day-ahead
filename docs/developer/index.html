Day Ahead Optimizer

Start developing

Use your GitHub fork to open a ready-to-use development environment in VS Code, following the Home Assistant workflow.

  1. Install VS Code and its Dev Containers extension, and start Docker with Linux containers. Install Git if needed.
  2. Create your fork on GitHub and copy its URL.
  3. Enter your fork URL below and click Open in VS Code.

A repository URL opens its default branch in VS Code. For a branch URL such as https://github.com/your-name/day-ahead/tree/my-branch, this page shows the manual VS Code clone instructions.

Continue in VS Code

Allow your browser to open VS Code. Confirm the clone and workspace trust prompts, then wait for the container build and automatic installation. The first installation can take several minutes.
